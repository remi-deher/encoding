# Médias pour les essais locaux

Placer ici une copie d’un petit fichier vidéo. Ce dossier est monté dans le worker Docker sous `/media/test` et associé à la bibliothèque « Médias de test ».

Le flow « Test — Inspection vidéo » analyse les métadonnées puis termine sans transformation. Depuis la bibliothèque « Médias de test », lancer « Découvrir / Actualiser les fichiers », puis sélectionner et traiter le fichier, par exemple `exemple.mp4`.

Les médias et résultats de ce dossier sont exclus de Git.
