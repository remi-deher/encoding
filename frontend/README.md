# Frontend

Application Angular du projet de traitement de bibliothèques multimédias.

## Développement local

```powershell
npm ci
npm start
```

L’application est ensuite disponible sur `http://localhost:4200`.

## Compilation

```powershell
npm run build
```

Le frontend est initialisé avec Angular Material pour fournir la base des composants d’interface partagés. L’accueil utilise pour le moment des données fictives ; aucune API backend n’est encore connectée.
